# Aplicativo do Instituto Assistencial FAÇA

Aplicativo mobile para o **Instituto Assistencial FAÇA**, com o objetivo de **engajar voluntários** e **facilitar doações**.

Projeto Integrador de Extensão (PIEX) — Curso de Análise e Desenvolvimento de Sistemas, Faculdades Vianna Júnior · 2026-2.

> 🚧 Projeto em desenvolvimento. Este documento será atualizado conforme o projeto avança.

## 📱 Sobre
Aplicativo desenvolvido em React Native como continuidade ao site institucional do Instituto FAÇA, dando mais alcance ao trabalho social da instituição.

## 🛠️ Tecnologias
- React Native (Expo)
- Firebase
- JavaScript
