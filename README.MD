# Site Institucional do Instituto Assistencial FAÇA

Ampliação do site institucional do **Instituto Assistencial FAÇA**, com o objetivo de **captar mais voluntários** e **fortalecer a presença da instituição na web**.

Projeto Integrador de Extensão (PIEX) — Curso de Análise e Desenvolvimento de Sistemas, Faculdades Vianna Júnior · 2026-2.

## 🏛️ Sobre o Instituto FAÇA
O **Instituto Assistencial FAÇA** é uma organização sem fins lucrativos de **Juiz de Fora/MG** que, há mais de seis anos, apoia pessoas em situação de vulnerabilidade social. Suas principais ações são:

- 🧠 **Comunidades terapêuticas** — workshops, treinamentos e palestras motivacionais
- 👶 **Gestantes** — enxovais e doações
- 🧥 **Doação de roupas**
- 🥪 **Lanches** às pessoas em situação de rua (quintas e domingos)
- 🤝 **Encaminhamento** voluntário a comunidades terapêuticas

📸 [@institutofaca](https://instagram.com/institutofaca)

🌐 **No ar:** https://institutofaca.org.br

## 💻 Sobre
Ampliação do site institucional do Instituto FAÇA, em continuidade ao trabalho do semestre anterior. O foco é **detalhar os projetos** da instituição, dar **destaque às campanhas e ações reais** e **ampliar a captação de voluntários**, além de melhorar a presença do site na web (SEO). Site estático, publicado e mantido pela própria instituição.

## 🚀 Como executar (local)
Site estático — basta abrir o `index.html` no navegador (ou usar a extensão **Live Server** no VS Code).

```bash
git clone <url-do-repositorio>
cd <pasta-do-projeto>
# abra o index.html no navegador
```

> A publicação (deploy) é feita pela equipe técnica do Instituto FAÇA, após reunião de aprovação.
